Note

The Compatibility column indicates the SvAnna application version that is compatible with given database files Version. The bracket [ is inclusive while ) is exclusive. For instance version 2304 works with SvAnna versions 1.0.3 and 1.0.4 but not with 1.1.0.

Note

The database files were moved from Google Cloud to Zenodo.

Use curl or wget utilities to download the files from command line:

$ wget https://zenodo.org/records/20281981/files/2605_hg38.svanna.zip
or
$ curl --output 2304_hg38.svanna.zip https://zenodo.org/records/20281981/files/2605_hg38.svanna.zip

Alternatively, use a GUI FTP client such as FileZilla.

Database folder structure

The folder structure differs a bit between the releases.

Since 2511_hg38 (newer releases), the database archive release has the following structure:

svanna-data
  |- checksum.sha256
  |- gencode.v38.genes.json.gz
  \- svanna_db.mv.db

The database folders of older SvAnna releases, including 2204_hg38, 2304_hg38, and 2402_hg38 had the following structure:

svanna-data
  |- checksum.sha256
  |- gencode.v38.genes.json.gz
  |- hp.json
  \- svanna_db.mv.db

Check the file integrity

Check that the download went well by running:

$ sha256sum -c checksum.sha256

All lines should end with OK.
